# potropokemon

Pokémon Box Cup — Team Builder

Como usar:
1. Abra index.html em qualquer navegador moderno.
2. Escolha 6 Pokémon.
3. Clique em "Exportar para Showdown".
4. Copie o texto para Pokémon Showdown > Teambuilder > Import/Export.

Regras de equipe
- Exatamente 6 Pokémon
- Máximo de 24 pontos
- Máximo de 1 Pokémon custando 7 ou 8 pontos

Critérios
1. BST histórico: valores correspondentes à era ADV (Gerações II-V).
2. Tier Smogon ADV: Uber, OU, UUBL, UU, RU, NU, PU, ZU, NFE, LC e banlists intermediárias.
3. Set fixo da Box: correções pequenas para casos em que o set/item fixo altera o valor esperado.

Observação
O tier competitivo é o sinal principal. O BST diferencia Pokémon dentro de patamares semelhantes, e o ajuste do set é deliberadamente pequeno para evitar contar duas vezes fatores que o tier do Smogon já considera.

Fontes carregadas pelo site
- Pokemon Showdown: data/mods/gen3/formats-data.ts
- pokemonData/Pokemon.csv, com reversão programática dos buffs de base stats posteriores à Gen V para #001-#386.
